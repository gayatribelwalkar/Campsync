# User Stories

# CampSync: A Resilient, Low-Bandwidth Consolidated NGO Healthcare & Inventory System

---

# Introduction

User stories describe the system from the perspective of different users. They help identify the requirements of the system in simple language and guide Agile development.

The primary users of CampSync are:

- Field Volunteer
- NGO Administrator
- Patient

---

# Field Volunteer User Stories

## US-01

As a Field Volunteer, I want to securely log in so that I can access authorized features.

---

## US-02

As a Field Volunteer, I want to register a new patient so that patient information is recorded digitally.

---

## US-03

As a Field Volunteer, I want to search existing patients offline so that duplicate registrations are avoided.

---

## US-04

As a Field Volunteer, I want to record patient vital signs so that doctors can make informed decisions.

---

## US-05

As a Field Volunteer, I want to record doctor observations and diagnosis so that patient treatment is documented.

---

## US-06

As a Field Volunteer, I want to request medical equipment for patients so that they receive the required support.

---

## US-07

As a Field Volunteer, I want to refer patients to hospitals so that critical cases receive further treatment.

---

## US-08

As a Field Volunteer, I want to continue working without internet so that healthcare camps are not interrupted.

---

## US-09

As a Field Volunteer, I want to know how many records are waiting for synchronization so that I know whether my work has been uploaded.

---

## US-10

As a Field Volunteer, I want my offline records to synchronize automatically when internet becomes available so that I do not have to upload them manually.

---

# NGO Administrator User Stories

## US-11

As an NGO Administrator, I want to manage volunteer accounts so that authorized users can access the system.

---

## US-12

As an NGO Administrator, I want to monitor all healthcare camps from one dashboard so that I can track ongoing activities.

---

## US-13

As an NGO Administrator, I want to view patient statistics so that I can analyze camp performance.

---

## US-14

As an NGO Administrator, I want to manage donated medical equipment so that equipment allocation is properly tracked.

---

## US-15

As an NGO Administrator, I want to assign equipment to patients so that donations reach the correct beneficiaries.

---

## US-16

As an NGO Administrator, I want to monitor equipment maintenance status so that damaged equipment can be repaired.

---

## US-17

As an NGO Administrator, I want to identify high-risk patients so that timely follow-up can be arranged.

---

## US-18

As an NGO Administrator, I want to generate reports so that I can evaluate NGO activities and prepare documentation.

---

## US-19

As an NGO Administrator, I want to receive notifications about pending synchronization and equipment shortages so that I can take timely action.

---

## US-20

As an NGO Administrator, I want to maintain secure patient records so that sensitive healthcare information remains protected.

---

# Patient User Stories

## US-21

As a Patient, I want to receive hospital referral notifications so that I know when and where to visit.

---

## US-22

As a Patient, I want to receive WhatsApp reminders so that I do not miss follow-up appointments.

---

## US-23

As a Patient, I want to provide feedback about donated medical equipment so that the NGO can improve its services.

---

## US-24

As a Patient, I want to request equipment maintenance through WhatsApp so that faulty equipment can be repaired.

---

## US-25

As a Patient, I want my healthcare records to remain confidential so that my personal information is protected.

---

# Summary
These user stories capture the primary expectations of all stakeholders and serve as the foundation for sprint planning, use case development, frontend design, and system implementation.
